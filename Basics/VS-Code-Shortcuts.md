1. Writing and Editing Code 

Shortcut| Use
"Ctrl + S"| Save code
"Ctrl + Z"| Undo
"Ctrl + Y"| Redo
"Ctrl + X"| Cut line or selected code
"Ctrl + C"| Copy line or selected code
"Ctrl + V"| Paste code
"Ctrl + /"| Comment / Uncomment code
"Ctrl + D"| Select the next matching occurrence
"Alt + ↑ / ↓"| Move line up / down
"Shift + Alt + ↑ / ↓"| Duplicate line up / down
"Ctrl + Shift + K"| Delete current line
"Shift + Alt + F"| Format the code

2. Finding and Navigating Code

Shortcut| Use
"Ctrl + F"| Find text
"Ctrl + H"| Find and replace
"Ctrl + P"| Open a file quickly
"Ctrl + G"| Go to a specific line
"F12"| Go to definition
"Alt + ←"| Go back
"Alt + →"| Go forward
"Ctrl + Space"| Show code suggestions

3. Important Development Shortcuts

Shortcut| Use
"Ctrl + Shift + P"| Open Command Palette
"Ctrl + Shift + E"| Open Explorer
"Ctrl + Shift + F"| Search across files
"Ctrl + " `| Open / close terminal
"Ctrl + B"| Show / hide sidebar
"Ctrl + N"| Create a new file
"Ctrl + W"| Close current file

4. HTML and Web Development

Shortcut| Use
Type "!" + "Enter"| Generate HTML boilerplate (Emmet)
"Ctrl + Space"| Show suggestions
"Shift + Alt + F"| Format HTML, CSS or JavaScript
